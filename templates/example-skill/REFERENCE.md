# Example Skill — Reference

A disclosed reference file: material the agent consults on demand, kept out of `SKILL.md` so the steps stay legible.

- **Sibling, not subfolder.** It sits next to `SKILL.md`.
- **UPPERCASE name for what it holds.** `FORMATS.md`, `GLOSSARY.md`, `KICKOFF.md`.
- **One topic per file.**
- **Reached by a pointer.** `SKILL.md` links it at the step that needs it; the pointer's wording decides whether the agent opens it.

Good candidates: a format or schema, a glossary, a checklist only one branch of the skill uses.
